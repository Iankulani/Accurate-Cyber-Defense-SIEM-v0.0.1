# Accurate-Cyber-Defense-SIEM-v0.0.1
Accurate-Cyber-Defense-SIEM-v0.0.1 is an early-stage Security Information and Event Management (SIEM) solution designed to centralize, analyze, and correlate security events in real time.
The tool collects logs from endpoints, servers, and network devices, transforming raw data into actionable security insights. It helps detect suspicious activities such as brute-force attempts, malware indicators, unauthorized access, and abnormal traffic patterns. With a lightweight architecture, Accurate-Cyber-Defense-SIEM-v0.0.1 supports basic alerting, log visualization, and incident awareness for small to medium environments. This version focuses on foundational threat visibility, improved monitoring efficiency, and laying the groundwork for advanced analytics, automation, and scalable cyber defense capabilities.

## How to clone the repo
```bash
git clone https://github.com/Iankulani/Accurate-Cyber-Defense-SIEM-v0.0.1.git
cd Accurate-Cyber-Defense-SIEM-v0.0.1
```
## How to run
```bash
python Accurate-Cyber-Defense-SIEM-v0.0.1.py
```
